\## ⚙️ Features (so far)

\- User system (register/login, online status, avatars)  

\- Dashboard with missions, activity feed, XP, and cash display  

\- Weekly spin (CSGO crate-style rewards)  

\- Casino with working blackjack PvP  

\- Gang creation \& influence system  

\- Modern UI with animated background
